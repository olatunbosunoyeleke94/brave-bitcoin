# brave-bitcoin

Practical Bitcoin payment infrastructure for everyday use in Africa.
Brave Bitcoin is an experimental project focused on making Bitcoin and Lightning payments more accessible to users and merchants in Nigeria and other African markets.
The project explores lightweight payment interfaces, Lightning infrastructure, merchant payments and Bitcoin infrastructure designed around real-world connectivity and resource constraints.

current status: Early-stage prototype / active development.

current focus: Building and testing the payment stack before controlled real-sats transactions.

Development milestones
 - Bitcoin infrastructure setup
 - Lightning infrastructure experimentation
 - USSD wallet prototype
 - Bitcoin payment API prototype
 - Controlled sats-moving tests (next)
 - Merchant pilot (next)
 - User pilot (next)
 - Production-ready payment infrastructure (next)
